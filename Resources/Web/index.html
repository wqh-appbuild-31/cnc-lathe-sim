    公差查询（ISO 286）

    H 是孔（下偏差 0），小写是轴。过盈不够/间隙不对，先对这张表，别靠手感。

    螺纹计算（公制）

    外螺纹牙高按 0.6134×螺距（车削参考），小径按大径 − 1.0825×螺距；精确尺寸以图纸和螺纹规为准。

    管螺纹速查（G / Rc）

    G 是 55° 圆柱管螺纹，不带锥度，靠垫圈/生料带密封。Rc 是 55° 锥管螺纹，锥度 1:16，尺寸看基准面：在基准面量大径，车的时候按基准距控制深度，不能只盯大径。

    三针法测螺纹中径

    公式 M = 基本中径 + 3×量针 − 0.866×螺距（60° 公制）。量出来的 M 比这个大，中径就偏大。最佳量针 = 0.577×螺距，正好骑在中径线上。

    锥度计算

    大头、小头、锥长、锥度比（1:K 的 K），空一个算一个；四个都填时按大头小头锥长重算锥度比。

    程序生成 · 螺纹（直 / 锥管）

    锥度 1:16。G92 的 R 按 FANUC 约定 = 起点半径 − 终点半径，往里越车越大所以是负数，模拟器已实测同一约定、能正确跑锥度。G76 锥螺纹模拟器不模拟（只按直的跑），选 G76 时「送入模拟器」会关掉，程序供真机使用。

    程序生成 · 椭圆 / 抛物线轮廓

    曲线用一小段一小段直线拟合后套 G71+G70，不用宏变量。步距越小越光滑、程序越长。

    G / M 代码速查

    FANUC / 广数车床常用代码，离线内置。个别代码各系统含义有出入（比如华中 G80 系列），以机床说明书为准。

    图纸符号速查

    形位公差 14 项（GB/T 1182）+ 制图常用符号合并去重。符号后面都跟了名称，个别符号在个别手机上显示不出来时，看名称和说明也一样查。

    程序库（存本机）

    存在这台手机的浏览器本地。清缓存、换浏览器、无痕模式都会清掉，重要程序记得复制出去备份。载入只换程序，毛坯按模拟器当前设置。

    切削参数推荐（经验参考值）

    线速度米/分，进给毫米/转。车间经验范围，不是标准：机床刚性、装夹、刀片型号差很多，先取中间值试切，再往上摸。

    车刀角度参考（经验值）

    硬质合金外圆车刀的常用搭配，经验值。刃磨和选刀片时对个大概，具体看刀片厂家样本和实际切削状态（断屑、震动、光洁度）。

    网纹 / 8 字油槽（参数参考）

    网纹（滚花）：按模数选滚花轮，模数 m 与节距 p 对照：m0.2 → p≈0.628；m0.3 → p≈0.942；m0.4 → p≈1.257；m0.5 → p≈1.571（p = π×m）。直纹是沿轴向的直齿，菱形（网纹）是左右斜纹交叉，花更牢、更防滑。

    滚花是挤压成形、材料会往外涨：滚花前直径 ≈ 要的滚花大径 − 0.5×节距（经验值），先少车一点、试滚一小段量准了再定尺寸。滚花时转速放低、进给慢一点、全程加油，别一刀压死。

    8 字油槽：轴套、衬套内孔里存油润滑的交叉油槽，两条螺旋槽交叉成 8 字形，油能布满整个摩擦面。经验尺寸：槽宽 3～6 毫米、深 0.5～1 毫米，两端不要贯通到边（留一点封油）。车床上一般用手工修磨的油槽钩刀、低转速慢慢拖出来，或者拉床拉制。这两个都只给参数参考，不生成程序。

    说明：数据口径与模拟器局限

    国标 / 标准表数据：公差（ISO 286）、公制螺纹牙型与粗牙螺距、G 管螺纹（GB/T 7307）、Rc 锥管螺纹（GB/T 7306 / ISO 7-1）、NPT（ASME B1.20.1）、莫氏锥度、三针法公式、形位公差与制图符号（GB/T 1182、GB/T 131）。锥螺纹 G92 的 R 按 FANUC 手册约定（起点半径 − 终点半径）；广数等系统上机前对一下本机说明书的符号定义。

    按收藏图录入：攻丝底孔表是范围值，以图为准，已全量核对：钢件公式 D − P 的结果 44 行全部落在图中范围内。

    经验参考值（不是标准，干活留余量）：切削参数推荐、车刀角度、粗糙度理论估算、硬度换算（近似对照，不同手册能差几个数）、滚花 / 油槽参数、各生成器预填的转速进给、模拟器自带程序里的转速进给表。

    模拟器的已知局限：不模拟钻孔（啄钻程序送进去会报警，是没给钻头建模，不是程序错）；端面环槽画不出真实形状（模型只认每个位置一个外径）；G76 不模拟锥度（锥螺纹用 G92 版送入验证）；不算刀尖圆弧补偿（G41/G42 不模拟），车锥面、倒角、圆弧时按「刀尖 R 补偿量」算出的数修正编程尺寸，或在真机上开补偿；切削时间和产量是估算。

    上机纪律：所有生成程序，第一件先空跑 / 单段、试切量过尺寸再批量，别直接批量下刀。

    程序库：存在手机浏览器本地（localStorage），清缓存、换浏览器、无痕都会丢；存储不可用时会有提示，不会静默丢程序，重要程序请复制出去备份。
